# 《金庸群侠传XR》MOD 创作者工坊 (JYXR Mod Studio)

这是一个专为《金庸群侠传XR》MOD 创作者打造的**纯前端、零后端依赖、Schema 驱动、高度解耦**的可视化 Web 内容编辑器。

---

## 一、核心特性与亮点

1. **零安装 · 纯前端运行**：
   - 依赖现代浏览器的原生 `File System Access API`，在 Chrome / Edge / Safari 中直接双击打开 `index.html`（或使用本地静态预览）即可直接使用！
   - 不需要配置 Node.js、Python、数据库等复杂的开发环境。
2. **本地磁盘无缝直写**：
   - 点击右上角【📂 打开 MOD 目录】，选中你的 MOD 文件夹（例如 `mods/wuxia-legend`）；
   - 在界面上修改攻击力、撰写剧情、添加新角色后，点击【💾 保存更改】，网页会**直接写回你电脑磁盘中的 JSON 文件**！
3. **单文件内核，守门校验**：
   - 全部逻辑（文件驱动、引用索引、校验器、六大工坊视图）内联在 `index.html` 一个文件里，保证 `file://` 双击打开也能直接运行，无需任何构建或模块服务器；
   - 仓库提供 `verify.sh` 语法守门：提交前抽出内联脚本执行 `node --check`，杜绝任何一处语法错误导致整站白屏。
4. **内置八大专业创作工坊**：
   - 🗡️ **神兵与道具工坊**：支持 100+ 神兵插画可视化图鉴挑选、大类与细分类型切换、武器/防具/饰品槽位、属性词条与专属天赋绑定。
   - 🥋 **武学与招式工坊**：外功 / 内功 / 绝技 / 传奇技四个子页签。外功支持 200+ 武学图标与攻击范围演练；内功支持阴阳刚柔、成长系数与技能词条 (Affix)；绝技支持目标/范围/双资源消耗与登场台词；传奇技支持触发条件、几率与附加状态。
   - 👤 **侠客与宗师工坊**：支持 300+ 侠客高清立绘图鉴挑选、全维度 10 大武学资质属性面板、已学内功/外功/专属绝技/天赋/装备全维度配置。
   - 🧩 **天赋与状态工坊**：天赋解锁点数、互斥天赋与词条；战斗状态增/减益与词条。
   - 🏪 **商店工坊**：商品行结构化编辑，支持物品 / 武学升满残章 / 元宝三类奖励与银两、元宝双价、限购。
   - ⚔️ **11×4 战棋与战场工坊**：11 列 × 4 行半即时战棋微型棋盘直观交互布阵，支持固定角色与随机刷怪组 (tier/头目)、布阵面向、必出战侠客，挑选战场背景原画与战斗音乐，并在棋盘上实时演示招式杀伤覆盖范围。
   - 📜 **剧情对白流编排**：按真实剧本结构递归编排对白、指令、跳转、战斗(胜负分支)、条件分支与抉择(选项内嵌步骤)，六个剧本文件页签切换，段落与指令名联想；内置原作者 [Story DSL](https://github.com/jyx-remake/story-dsl) 引擎 (MIT)，一键切换 **DSL 源码模式**，像写剧本一样创作剧情——实时语法诊断（错误行号定位）、编译保存为游戏 JSON IR，存量剧本可无损往返（反编译 ↔ 编译逐字节一致）。
   - 🔍 **全局健康检查**：扫描全部已载入 JSON（宽松解析对齐游戏加载器），排查角色、武学、状态、物品、商店、战棋、剧情间的悬空断裂引用与战棋站位规则，防手抖打错字。
5. **数据安全三重保障**：保存如实区分「已写磁盘 / 仅浏览器内存」；未落盘更改可一键导出或挂载本地 MOD 目录批量回写；编辑内容自动存入浏览器草稿，刷新或崩溃后可恢复。

## 二、如何启动使用？

### 方式 1：Mac 双击启动（最简单）
在访达（Finder）中进入 `tools/mod_editor/`，双击 **`启动MOD编辑器.command`**，脚本会自动寻找空闲端口、启动本地静态服务并打开浏览器，获得一键极速载入与原生磁盘直写体验。

### 方式 2：直接双击或用浏览器打开
在访达（Finder）中进入 `tools/mod_editor/`，双击 **`index.html`** 用 Chrome 或 Edge 浏览器打开即可。

### 方式 3：使用极简静态预览服务
如果你本地终端方便，可以在项目根目录下执行：
```bash
python3 -m http.server 8080
```
然后在浏览器访问：`http://localhost:8080/tools/mod_editor/`。

## 三、快速上手指引

1. 打开编辑器网页，点击右上角的 **【📂 打开 MOD 目录】**；
2. 在弹出的系统文件夹选择器中，选择你的 MOD 目录（例如 `mods/wuxia-legend`）；
3. 浏览器会提示是否授权读写权限，点击 **【允许 / 查看文件】**；
4. 顶部标签切换：
   - 点击 **【🗡️ 神兵与道具工坊】**：左侧搜索“天机神剑”，右侧即可自由改动攻击数值；
   - 点击 **【📜 剧情对白流编排】**：左侧选中“新手村_南贤开场”，右侧即可看到天机老人的登场对白与分支选项；
5. 点击右上角或表单顶部的 **【💾 保存更改】**，改动瞬间写回磁盘！
6. 切回 Godot 运行游戏，你的修改立即在游戏中生效！
